This is the GitHub repo that holds all the relevant files my post-project assignment to create a fully functional UNCP ACM Webpage. 
The webpage functions by being hosted locally relying on MySQL and Apache, which is included in the XAMPP application, All the files (excluding member2.sql and memberpw2.sql) are the files that build the actual webpage's frontend (through HTML and CSS) and its backend (through PHP). 
Member2.sql and memberpw2.sql are exported files from the database (hosted in MySQL) of the most up to date version of the database and its tuples. When the webpage is running locally and a user wishes to sign up, all they need to do is enter their first name, last name, email, password, and a deposit amount (no real money is managed), and website will automatically update the database.
